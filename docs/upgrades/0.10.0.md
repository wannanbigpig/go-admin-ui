# 0.10.0 首次部署说明

本版本是首次公开发布，支持后端范围由 `docs/release.json` 的 `compatibleBackend` 声明。版本一致不代表自动完成真实环境验收；后续版本升级必须指定上一 Tag。

## API 变更

依赖个人工作台/日志/待办、动态菜单与按钮权限、HttpOnly refresh cookie、个人资料安全校验等后端契约。发布前核对 API 路径、参数必填性、响应字段、错误码、权限码和 OTP/会话语义。当前 OpenAPI 缺少完整业务 schema，不直接生成 Client；参数与响应展示仍需核对真实请求和后端资源。

## 升级顺序

先核对后端支持范围及后端升级说明，准备配置和备份；后端兼容时可先升级后端再发布前端。若认证/菜单/字段不兼容，使用维护窗口或明确的兼容过渡版本，协调前后端切换。静态资源先上传到独立发布目录，验收后原子切换入口，保留上一版资源供现有浏览器会话使用。不可用清空数据库来解决前端版本不匹配。

## 回滚限制

保留上一前端产物及其后端支持范围。只有后端仍兼容旧契约时才能单独回退前端；否则与后端一起回退或向前修复。新前端资源与旧 HTML 混用、未迁移的菜单权限、已撤销会话等不能仅靠刷新页面修复。

## 验证

类型、Lint、测试、生产构建与浏览器回归通过后再打 Tag；目标环境验证登录/续期、菜单与按钮、资料修改、文件、任务、待办和权限失败场景。`dist/build-info.json` 记录源码版本、commit、构建时间与 dirty 状态，测试结果不等于生产联调完成。
