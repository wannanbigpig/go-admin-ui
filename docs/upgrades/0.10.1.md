# 0.10.1 发布与部署说明

v0.10.0 Tag 的浏览器回归在干净 CI 环境中失败，未生成正式发行产物。本版本保留原 Tag 作为代码比较基线，以 v0.10.1 提供静态资源包。

## API 变更

本版本没有修改后端接口调用契约，支持范围仍为 `>=0.10.0 <0.11.0`，推荐配套后端正式版本 v0.10.1。CI 使用 `.env.example` 的公开默认值，默认启用国际化、同源 `/admin` API；浏览器测试显式启用国际化和 Mock。

## 升级顺序

核对后端兼容范围，先准备后端 v0.10.1，再将前端静态资源上传到独立发布目录并原子切换入口。跨域 API 地址等部署配置应在目标构建中显式设置，不把本机环境文件当作发行构建的一部分。

## 回滚限制

保留实际部署过的前端产物及配置。v0.10.0 没有正式静态资源包，不依赖其 Release 回滚；回退前确认后端支持旧前端，不混用新 HTML 与旧资源。

## 验证

不包含本机 `.env` 的干净环境中验证多语言弹窗、抽屉、表单和窄屏交互，执行完整浏览器回归、类型检查、lint、单元测试和生产构建。检查 `dist/build-info.json` 的版本、commit、dirty 与正式 Tag；目标环境仍需验证登录、续期、动态菜单及 API 配置。
